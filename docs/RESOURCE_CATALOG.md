# Open Biomedical Research Resource Center — curated directory

**Verified/reviewed:** October 27, 2026. This is a starter catalogue, not every biomedical resource on the internet.

**42 catalog entries.** Access descriptions refer to the described public interface or software—not guaranteed free hosting, data redistribution, commercial permissions, lab materials, compute, or clinical use.

**Safety boundary:** Public research and educational directory only. No identifiable patient data, automated clinical treatment recommendations or simulated results presented as validated drug evidence.

## How to interpret access labels

- **Free public:** Read or query accessible public materials at no charge. This says nothing about the right to bulk copy an entire provider site.
- **Free public subset, controlled access:** Search and download the open data, but restricted human genomic or clinical data require institutional authorization.
- **Free software:** No software license fee; execution may need hardware, computation, storage, training, or specialized expertise.
- **Commercial products + free learning:** A resource can offer useful free documentation while its physical models, lab assays and services remain paid.

## Suggested research workflows

1. **Learn about NAMs:** BrainXell resource library → NIH NCATS Tissue Chips → NIEHS NICEATM validation → EPA CompTox.
2. **Disease evidence:** PubMed/Europe PMC → cBioPortal/GDC/GEO → CELLxGENE/HuBMAP → Human Protein Atlas.
3. **Hypothesis prioritization:** DepMap + Cell Model Passports → Reactome + STRING → Open Targets + CIViC + ChEMBL.
4. **Simulation:** BioModels → Morpheus or PhysiCell with documented assumptions, calibration and negative controls.
5. **Human translation:** ClinicalTrials.gov + specialist review; computational results are not clinical recommendations.
6. **Publish reproducibly:** Galaxy / Bioconductor → source code and data provenance → static website on GitHub Pages or Cloudflare Pages.
